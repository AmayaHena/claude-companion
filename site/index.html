See what Claude Code does, not what it says.

A read-only terminal viewer for a live session: commands, output, diffs. Deterministic, offline, sanitised.

$ go install github.com/AmayaHena/claude-companion/cmd/claude-companion@v1.0.0

Source on GitHub Release v1.0.0

Deterministic.Offline.Read-only.

Deterministic
The screen is a pure function of the transcript file, the terminal width and your time zone. No randomness, no timers, no state between runs. The only clock read is the picker's "3 min ago".
Offline
No socket-capable package in the binary: no net, no net/http, no TLS. No telemetry, no update check, no model call. Everything on screen comes from bytes already on your disk.
Read-only
Transcripts are opened for reading and polled by size. The tool writes no file, no cache, no config, and never touches Claude Code's state. Run it against a live session with nothing at risk.

One row per action, in your terminal's own palette.

Each row starts with the clock and a glyph. Every string from the transcript is sanitised before it reaches the screen, so a session's output cannot drive your terminal.

Audited before v1, with checks you can rerun.

Five lenses, fifteen independent agents, every finding handed to a skeptic told to refute it. Ten findings verified, none refuted, all fixed or documented. The claims are backed by tests and by commands anyone can run.

No network

No socket-capable package in the binary's dependency graph.

go list -deps ./cmd/claude-companion | grep -E '^(net|net/http|crypto/tls)$'
(prints nothing)

Read-only

Four filesystem calls in product code, all reads.

grep -rn --exclude='*_test.go' 'os\.\(Create\|WriteFile\|OpenFile\|Mkdir\|Remove\)' cmd internal
(prints nothing)

Untrusted input is inert

Escape sequences, controls and invisible format characters never reach the screen.

go test ./... -run 'Sanitis|Controls|Marks'
ok

No build-machine paths

The documented build keeps your home directory out of the binary.

go build -trimpath ./cmd/claude-companion && strings claude-companion | grep -c "$HOME"
0

Every guard was mutation-checked: removing it makes its test fail. The full list of findings, fixes and accepted limits is in the README.

Try it without a session.

Run the bundled replay in one terminal, the viewer in another. The replay appends one line every 0.8 s.

sh demo/play.sh
CLAUDE_CONFIG_DIR="$PWD/demo" claude-companion demo1111

Without an argument, claude-companion lists your ten most recent sessions and opens the one you pick.

Built in Go with Bubble Tea. Shows a transcript as it is: redacts nothing, sends nothing anywhere.
